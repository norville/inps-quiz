Quiz INPS 499 — Assistenti informatici

Banca dati delle domande non trovata.

Le domande sono lette dal file inps-quiz-questions.json. Così puoi integrarle o correggerle senza toccare questa pagina. Aperta con un doppio clic, la pagina non può leggere il file da sola: caricalo una volta col pulsante qui sotto e resterà in memoria. Servita via HTTP (python3 -m http.server nella cartella) viene invece letta in automatico a ogni avvio.
Formato del file

Ogni domanda richiede parte, sezione, n, testo, da 2 a 6 options e risposta con la lettera corretta. Il campo id è facoltativo: se lo ometti viene ricavato da parte, sezione e numero, ed è la chiave con cui vengono associate le statistiche storiche. L'elenco parti serve solo a dare un titolo e un ordine: le parti non elencate vengono aggiunte in coda automaticamente.

{
  "parti": [
    { "id": "Parte I", "titolo": "Informatica di base e gestione di sistemi di backup e recovery" }
  ],
  "domande": [
    {
      "parte": "Parte I",
      "sezione": "Capitolo 1 — Dai segnali elettrici agli algoritmi",
      "n": 1,
      "testo": "Un byte è composto da:",
      "options": [
        { "l": "A", "t": "2 bit" },
        { "l": "B", "t": "4 bit" },
        { "l": "C", "t": "8 bit" },
        { "l": "D", "t": "16 bit" }
      ],
      "risposta": "C"
    }
  ]
}

Quiz INPS 499 — Assistenti informatici

Per argomento

Tutte le domande di una parte del manuale, in ordine casuale. Nessun limite di tempo.

Simulazione esame

60 domande estratte da tutte le parti, con almeno una domanda per parte. Cronometro di 120 minuti.

Le alternative sono sempre mescolate. Nel manuale il 54% delle risposte corrette è la lettera B (A 14%, C 27%, D 5%): conservare l'ordine originale porterebbe a memorizzare la posizione invece del contenuto, con punteggi gonfiati.
