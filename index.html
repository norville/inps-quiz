Le domande sono lette dal file inps-quiz-questions.json accanto alla pagina. Se stai vedendo questo messaggio sul sito, il file non è raggiungibile: riprova più tardi. Se hai aperto la pagina con un doppio clic da disco, il browser non le permette di leggere il file da sola: servila via HTTP (python3 -m http.server nella cartella) oppure caricala a mano col pulsante qui sotto.
Formato del file

Ogni domanda richiede part, section, n, text, da 2 a 6 options e answer con la lettera corretta. Il campo id è facoltativo: se lo ometti viene ricavato da materia, sezione e numero, ed è la chiave con cui vengono associate le statistiche storiche. L'elenco parts serve solo a dare un titolo e un ordine: le materie non elencate vengono aggiunte in coda automaticamente.

{
  "parts": [
    { "id": "Parte I", "title": "Informatica di base e gestione di sistemi di backup e recovery" }
  ],
  "questions": [
    {
      "part": "Parte I",
      "section": "Capitolo 1 — Dai segnali elettrici agli algoritmi",
      "n": 1,
      "text": "Un byte è composto da:",
      "options": [
        { "l": "A", "t": "2 bit" },
        { "l": "B", "t": "4 bit" },
        { "l": "C", "t": "8 bit" },
        { "l": "D", "t": "16 bit" }
      ],
      "answer": "C"
    }
  ]
}
